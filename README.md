# Tetris-Game



A classic Tetris game that runs in the browser, built with HTML, CSS, and JavaScript.
Features
All the classic pieces, rotation, and line clearing
Score and level system
Next-piece preview and ghost piece
High score saved in the browser (localStorage)
Pause and resume (P or Esc)
Sound effects for move, rotate, hard drop, line clear, pause, resume, start, and game over
Tech Stack
HTML
